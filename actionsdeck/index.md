ActionsDeck connects directly to GitHub so you can browse repositories and workflows,
inspect runs and logs, manage eligible actions, and preview downloaded artifacts.

## Help and policies

- Read the [Privacy Policy](/actionsdeck/privacy/).
- Visit [ActionsDeck Support](/actionsdeck/support/) for help or to report a problem.

ActionsDeck requires a GitHub account and appropriate repository permissions. Features
available to you depend on the permissions granted to your GitHub token.
