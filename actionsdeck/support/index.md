## Before requesting help

1. Confirm that your device can reach GitHub.
2. Check that your GitHub token has permission to access the affected repository and
   GitHub Actions feature.
3. Refresh the screen after reconnecting if the app was offline.
4. Include your ActionsDeck version, Apple device model and OS version in your report.

## Contact support

[Open an ActionsDeck support request](https://github.com/patelsid1211/Github-CICD-Mobile/issues/new)
in the public GitHub issue tracker. Describe what you expected, what happened, and the
steps needed to reproduce it.

Do **not** include GitHub tokens, passwords, private repository names, confidential log
content or downloaded artifacts in a public issue. Remove sensitive information from
screenshots and diagnostic text before attaching them.

You can also review existing
[ActionsDeck support requests](https://github.com/patelsid1211/Github-CICD-Mobile/issues)
to see whether a problem has already been reported.

## Privacy questions

For information about credentials, GitHub data and on-device storage, read the
